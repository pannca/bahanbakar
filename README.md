# Aplikasi Form Isi Bensin (PHP OOP)

Aplikasi sederhana berbasis PHP menggunakan konsep **Object Oriented Programming (OOP)** untuk menghitung total harga pembelian bahan bakar lengkap dengan PPN 10%.

## 🎯 Fitur
- Input jumlah liter bensin
- Pilih jenis bahan bakar
- Hitung total harga otomatis
- Hitung PPN 10%
- Tampilkan struk pembelian

## 🛠️ Teknologi
- PHP Native (OOP)
- HTML
- CSS (Bootstrap 4)

## 📂 Struktur File
- index.php → file utama aplikasi

## ▶️ Cara Menjalankan
1. Simpan file di folder:
C:\xampp\htdocs\bensin\

2. Jalankan Apache di XAMPP
3. Buka browser:
http://localhost/bensin/


## 🧮 Contoh Harga
| Jenis BBM              | Harga/Liter |
|------------------------|-------------|
| Shell Super            | Rp 15.420   |
| Shell V-Power          | Rp 16.130   |
| Shell V-Power Diesel   | Rp 18.310   |
| Shell V-Power Nitro    | Rp 16.510   |

## 📌 Konsep OOP yang Digunakan
- Class & Object
- Inheritance (extends)
- Encapsulation (private, protected, public)
- Method
